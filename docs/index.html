What It Does

Render Mermaid source from pasted code, bundled samples, or shared diagram links, then adjust Theme, Look, Width, Scale, and Background for preview and capture.

Exports

Copy Link creates a shareable Mermaid Snapper URL. SVG copy and download use the rendered diagram directly. PNG export may be disabled when browser security blocks SVG-to-canvas export.

Mouse Controls

Drag the preview to pan around large diagrams. Hold Ctrl and use the mouse wheel over the preview to change Scale in 5% steps.
